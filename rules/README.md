## 通用红线（所有平台共性）

1. 只做手工、低影响验证；禁止扫描器、自动化批量探测、高频请求、DoS/DDoS。
2. 只测授权范围内资产；未授权资产、第三方资产、内网系统一律不碰。
3. 只用自行注册的测试账号；不触碰真实用户数据。
4. 数据最小化：证明即可，不拖库、不批量读取、不二次利用。
5. 命令执行只证明存在；不落 webshell、不读源码/敏感文件、不扫内网。
6. 不保存/传播漏洞资料；未修复前不对外披露。
7. 禁止社会工程、物理测试、钓鱼、伪造。
8. AI 辅助发现必须人工复现后才能提交。
